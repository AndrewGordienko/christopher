# Competitive research baseline

Checked14September2026. This is a vendor-reported reference, not an independent coverage audit or an OutageHub capability claim.

[PowerOutage.us products](https://poweroutage.us/use-our-data) currently advertises US, Canada and UK API data, Canadian coverage of95%, ten-minute refreshes and utility-sourced GeoJSON. It explicitly describes operational uses for telecom, MSPs and multi-location businesses. Canada coverage alone therefore cannot establish a unique reason to buy OutageHub.

For each actual prospect, refresh this comparison and current OutageHub product evidence: covered utilities/geography, location matching, event granularity, latency, historical depth, ETR/cause availability, webhooks, licensing, economics, API integration and support. Unknown values stay unknown. Do not infer comparable coverage, a price advantage, superior quality or a data gap without evidence.
